# Compliance: contest rule to evidence

Project: Qubro Next-Gen Spatial Command & Control Center (CCC). Contest: Meta VR Start Developer Competition 2026. Track: Productivity. Division: New Experience.
Live app (free, no login): https://lordarris2025.github.io/-qubro-spatial-ccc-/app/

Status words: VERIFIED = checked by the entrant or in code; PENDING = waiting on something outside the code; "not yet measured / verified" = deliberately not claimed.

| Hands-first: 100 % direct hand tracking, no controllers | The VR session requires the `hand-tracking` feature; every interaction reads tracked hand joints; controller models and rays are hidden and a notice asks the user to put controllers down. If hand tracking is off, a plain-language message says how to turn it on (no dead screen). The emulator's "Controller [L]/[R]" panels are emulator UI, not Qubro UI. | [docs/USER_GUIDE.md](docs/USER_GUIDE.md) "Hands first"; [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) section 6.1 |

The main demo is a single button (SIMULATE INTRUSION) then a hand authorization. | [docs/LIVE_APP_FOR_JUDGES.md](docs/LIVE_APP_FOR_JUDGES.md) |

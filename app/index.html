Qubro Next-Gen Spatial Command & Control Center (CCC)

Qubro is a WebXR command center built with IWSDK for standalone VR headsets. It is hands-first: 100 percent direct hand tracking, no controllers. You stand in a virtual data-center command room. Four sector AIs cover cybersecurity, drones and robotics, LiDAR and radar, and CCTV with door access. An AI model answers each order from the live state of the building, a vision model is integrated for camera frames (simulated in the demo), and a voice model provides speech input. If no model is reachable, a labeled fallback mode keeps the app running. The AI can never authorize an action: only the operator's hand gesture can.

How to try it

  • Headset: open this page in the headset's browser with hand tracking on, press ENTER VR (hands only). Pinch a desk button, pull it like stretchy plastic, let go.
  • Computer: drag down to see the desk, click a desk button, or press 1 (simulate attack), 2 (authorize), 3 (reset), K (check all sectors), T (type an order), V (talk). Drag the mouse to look around.
  • Not sure what to ask the AI? Press H (or the GUIDE / HELP desk button in VR): it lists example questions, such as "cybersecurity status?", "what is the satellite status?", "show me CCTV".
  • Each visit has its own simulation, so nothing you do affects other visitors.
